Auslan Fingerspelling Web App

Capstone project turned passion build with Victor Goh. I focused on the fingerspelling feature: training pipeline, architecture choices, and on-device inference that runs entirely in the browser.

Why

Auslan literacy is an accessibility gap. We wanted a lightweight, gamified way to practice fingerspelling without server costs or privacy tradeoffs. The app had to run fully on-device.

What

A browser-based Auslan fingerspelling recognizer that uses MediaPipe for real-time hand landmarks and a custom TensorFlow model for letter classification. Static deployment, no backend.

Design Decisions

  • Image-based CNN inference was too heavy and costly for a static site.
  • MediaPipe Hand Landmarker provides a compact, real-time abstraction.
  • Landmark tensors enabled small MLPs instead of heavy CNN/RNN models.

Training Flow

  1. Collect raw images for 26 classes (A-Z).
  2. Run MediaPipe Hand Landmarker on each frame.
  3. Extract worldLandmarks (3D), reshape to [21,3,2].
  4. Pad missing hand landmarks with [-1,-1,-1].
  5. Train lightweight classifiers with validation split and LR schedule.
  6. Export best model to TensorFlow.js for in-browser inference.

Architecture Choices

  • Simple 3-layer MLP as a strong baseline.
  • Bilateral MLP with per-hand branches and feature fusion.
  • Residual fusion to improve accuracy without adding much latency.
